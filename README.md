# Little by Little - Habit Tracker

A small, private daily habit tracker built for real life.

## What it does
- Daily, weekend-only, and weekly habits
- Date navigation without carrying unfinished tasks into tomorrow
- One-tap completion tracking
- Daily completion percentage
- Categories for Morning, Body, Mind, Growth, Career, Care, Home and Night
- Add and remove habits
- Persists everything in browser `localStorage`
- Responsive desktop/mobile layout

## Run locally

```bash
npm install
npm run dev
```

The app is intentionally backend-free: your check-ins stay in the browser you use.
